# Система управління замовленнями та виробничим графіком

Ця структура призначена для масштабованого фронтенд-сайту на базі HTML + CSS, підготовленого до майбутньої бекенд-інтеграції. Система забезпечує управління замовленнями, виробничими графіками, задачами, співробітниками та аналітикою.

## Принципи розробки

- **BEM іменування**: блок__елемент--модифікатор
- **Модульні стилі**: розділення на загальні, компоненти та сторінкові CSS
- **Кожна сторінка** має власний CSS-файл в папці `styles/pages/`
- **Навігація** організована за групами: Керування, Ресурси, Аналітика, Система
- **Семантичний HTML**: правильна структура, ARIA-атрибути
- **Responsive дизайн**: адаптація для планшетів та мобільних пристроїв

## Веб-сторінки системи

### Керування

#### 1. **Головна панель (Dashboard)** — `index.html`
- Загальна інформація про систему
- Ключові метрики та статистика
- Графіки та діаграми
- Швидкі дії та навігація на інші сторінки

#### 2. **Графік виробництва** — `production-schedule.html`
- Часова шкала виробничих робіт
- Розподіл задач за співробітниками
- Фільтрація за датою, терміном, відділом
- Таб-панель: перегляд за відділами або замовленнями
- Кольорова кодифікація завдань (червоні, зелені, сині блоки)
- Пагінація та контроль кількості рядків

#### 3. **Управління замовленнями** — `order-management.html`
- Список всіх замовлень з деталями
- Статуси: плановані, в процесі, завершені
- Фільтрація та пошук по замовленнях
- Дані: назва, клієнт, дата створення, дата завершення
- Можливість створення та редагування замовлень

#### 4. **Виробничі задачі** — `production-tasks.html`
- Список задач, прив'язаних до замовлень
- Статуси задач, плани та фактичне завершення
- Розподіл по виконавцям (співробітникам)
- Фільтри за статусом, виконавцем, замовленням
- Деталі: назва, опис, плани дати, статус, відповідальний

### Ресурси

#### 5. **Управління співробітниками** — `employees.html`
- Список всіх співробітників з детальною інформацією
- Поля: П.І.Б., посада, відділ, кваліфікація, дата найму
- Пошук та фільтрація по відділам та посадам
- Можливість додавання нових співробітників
- Редагування та видалення записів

#### 6. **Управління підрозділами** — `departments.html`
- Список всіх структурних підрозділів
- Керівник підрозділу, кількість співробітників
- Розподіл бюджету та ресурсів
- Фільтрація та пошук

#### 7. **Продукція та послуги** — `products-services.html`
- Каталог виробничої продукції
- Послуги, які компанія надає
- Характеристики, ціни, цільовий ринок
- Управління асортиментом

#### 8. **Склад та ресурси** — `inventory-resources.html`
- Облік матеріалів і комплектуючих
- Залишки на складі
- Витрати ресурсів по замовленнях
- Алерти про низькі залишки

### Аналітика

#### 9. **Ефективність співробітників** — `employee-performance.html`
- Метрики продуктивності за період
- Графіки виконання задач та часу
- Середня тривалість завдань
- AI-рекомендації з оптимізації
- Рейтинги та порівняння

#### 10. **Використання ресурсів** — `resource-usage.html`
- Аналіз витрат матеріалів та обладнання
- Ефективність використання ресурсів
- Прогнози та планування
- Рекомендації з оптимізації

#### 11. **Витрати та прибуток** — `finance-report.html`
- Фінансовий звіт по замовленнях
- Витрати по проектам та категоріям
- Прибутковість по видах діяльності
- Касові потоки, прогнози

### Система

#### 12. **Журнал подій** — `activity-log.html`
- Логування всіх дій користувачів
- Фільтр по типу дії, користувачу, датам
- Аудит змін і видалень
- Експорт звітів

#### 13. **Ролі та права доступу** — `roles-permissions.html`
- Управління користувальницькими ролями
- Призначення прав доступу
- Налаштування рівнів доступу до функцій
- Групи користувачів

#### 14. **Налаштування системи** — `settings.html`
- Профіль користувача
- Налаштування обліку
- Параметри системи
- Експорт/імпорт даних

## CSS структура

### **main.css** — Основні стилі
- Змінні CSS (кольори, радіуси, тені)
- Глобальні стилі та reset
- Макет сторінки (sidebar, topbar, main-content)
- Типографія
- Базові компоненти

### **layout.css** — Макети
- Grid та Flexbox макети
- Позиціонування елементів
- Адаптивна верстка

### **components.css** — Компоненти UI
- Кнопки (primary, secondary, ghost)
- Форми та поля введення
- Карточки та панелі
- Таблиці та списки
- Табс та модальні вікна
- Значки та бейджі

### **utils.css** — Утилітарні класи
- Spacing (margin, padding)
- Text utilities (колір, розмір, вага)
- Display utilities (hide, show)
- Інші допоміжні класи
